# Validore interface

This is a refinement of the existing brand. Logo assets in public/logo are unchanged.

Palette: navy #0A1628, gold #C8A860, gold dark #B8963E, cream #F5F0E8, ivory #FAFAF7, charcoal #1C1C1C. Existing angular corners remain the brand motif.
Typography: original Geist Sans for interface text; Geist Mono for code and numerical data. The fonts are self-hosted under the SIL Open Font License.

Dashboard mode: Operate. A persistent desktop navigation column contains product modules and account actions. On phones it becomes a labeled disclosure above the workspace. Current page, real credit access and keyboard focus are visible.

Layout:
    Desktop: [navigation | page heading / task / result]
    Phone:   [brand + menu] / [optional navigation] / [task]

The idea wizard retains eight input steps and a review step. Fields share their validation with the API; the review supports editing; retries preserve the saved idea. Analysis progress reflects the persisted job, with a clear route to report history.

Landing mode: Persuade. Retain the original content and brand; refine spacing, mobile wrapping and keyboard access. Auth mode: Operate. Show request feedback, preserve safe return paths, and complete password recovery.

Quality floor: touch targets, visible focus, labels, semantic status and error messages, long-content wrapping, reduced motion, recovery and empty states. Changes preserve factual product claims unless explicitly corrected with implementation evidence.
