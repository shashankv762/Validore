# Validore logo assets

These assets reuse the original vector paths from the supplied `validore_logo_system.svg`. The faceted ore mark, angular check, custom lowercase lettering, and diamond above the i are preserved. Presentation panels and editor metadata are omitted from the web assets.

- `validore-logo-dark.svg`: ivory lettering for dark surfaces.
- `validore-logo-light.svg`: dark lettering for light surfaces.
- `validore-icon.svg` and `validore-favicon.svg`: the original faceted mark.
- `validore-report.png`: raster wordmark for PDF and Word exports.
- `validore-google-consent.png`: app icon for the OAuth project's Google Auth Platform Branding settings. Updating this file does not update Google's external consent screen; the project owner must upload it and save the branding configuration.

Brand colors: ink `#0B0E13`, gold `#E0A526`, light gold `#F0C04E`, highlight `#F8DE95`, deep gold `#A86A0A`, ivory `#F4EFE6`.
